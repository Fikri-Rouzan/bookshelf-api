# Bookshelf API

## 📌 Deskripsi

Layanan back-end RESTful API untuk pengelolaan katalog dan catatan buku. Layanan ini menyediakan endpoint lengkap untuk operasi CRUD (Create, Read, Update, Delete) data buku, validasi payload permintaan secara ketat, serta fitur penyaringan data fleksibel berdasarkan nama buku, status membaca, dan status penyelesaian bacaan.

## ⚙️ Petunjuk Pengaturan

1. **Prasyarat**
   - Node.js 24 atau lebih baru.
   - Git terinstal di komputer.
   - PNPM 10 terinstal di komputer (Opsional).
   - Postman terinstal di komputer.

2. **Clone Repositori**

```bash
git clone https://github.com/Fikri-Rouzan/bookshelf-api.git
cd bookshelf-api
```

3. **Install Package**

```bash
# Dengan npm
npm i

# Dengan pnpm
pnpm i
```

4. **Menjalankan Program**

```bash
# Dengan npm
npm run start

# Dengan npm nodemon
npm run start-dev

# Dengan pnpm
pnpm run start

# Dengan pnpm nodemon
pnpm run start-dev
```
